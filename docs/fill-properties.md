# Массовое заполнение специфических общих свойств

Содержание понятия = ближайший род + видовое отличие. Род (kod 14) уже
есть у 99.9% узлов; существенный признак (15) — у 0.1%. Этот проход
заполняет **свойства**, не виды.

Заполняет агент (не локальная модель): факты пишутся в скрипт, движок
валидирует. Ни одного LLM-вызова на якорь.

## Экономия токенов

1. **Свойство — на высший род, не на вид.** `животное —[22]→ движение`
   покрывает сотни потомков через наследование. Вид получает ребро
   только если это *отличие* (пингвин —[22]→ полёт 0) или объект
   уже, чем у рода (птица —[22]→ полёт vs животное —[22]→ движение).
2. **Один проход, один файл фактов.** Нет EXPAND/RELATE по якорям,
   нет «already known»-списков в промпте, нет JSON. Повторный прогон
   идемпотентен (`validate` режет дубликаты).
3. **Не создавать узлы без нужды.** Объект ребра — уже существующее
   понятие (полёт, перо, питание). Новые узлы — только шкалы для kod 15
   (теплокровность) и явные пробелы (фотосинтез, яд).
4. **Не просить определений.** `define()` собирает их из графа.
5. **Не слать базу в модель.** Контекст — онтология в голове агента
   + frontier-инвентаризация (раз на проход, локально).
6. **Сигнатуры расширяем, а не обходим.** Процесс/состояние не были
   субъектом 15/20 (только предмет/действие) — `явление` (2535)
   покрывает действие ⊂ явление.

Оценка: ~15 новых понятий + ~400 рёбер ≈ один прогон скрипта.
Наивный «свойства каждого из 3300 листьев» был бы ×10 фактов и
дубликатами, которые `prune_inherited` всё равно снял бы.

## Что пишем

| kod | роль | куда |
|---|---|---|
| 15 | видовое отличие (содержание) | субъект ⊂ предмет/явление, объект ⊂ свойство |
| 20 | общий признак / часть | то же + объект ⊂ предмет |
| 21 | назначение | артефакт → действие/процесс |
| 22 | способен к | организм/устройство → процесс |
| 23/24 | материал / содержимое | артефакт |
| 26 | кто пользуется | артефакт → человек |
| 27 | пациенс | процесс → предмет |
| 70/71/74 | каузальные | без сигнатуры |
| 0 strength | отрицание наследования | пингвин не летает |

Не пишем: 61 координаты, новые виды, английские существительные-выдумки,
прилагательные как узлы.

## Порядок

1. Расширить сигнатуры 15/20/21/22/27 на `явление`.
2. Добавить недостающие объекты (теплокровность, фотосинтез, …).
3. Свойства высоких родов (организм…артефакт…вещество…процесс).
4. Видовые отличия (млекопитающее/птица/рыба/…; ключи артефактов).
5. `rebuild` / `define` / prune inherited / дамп.

Прогон: `python tools/fill_props1.py`
