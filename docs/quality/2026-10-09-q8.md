## Sources and scope

The model hierarchy uses the computational senses of model and neural network.
A language model concerns token-sequence probabilities; an LLM is a specialization.
The backpropagation record denotes a network trained by that method, not the
algorithm itself. These are ontology classifications based on the
[Google ML glossary](https://developers.google.com/machine-learning/glossary)
and [language-model introduction](https://developers.google.com/machine-learning/crash-course/llm).

An array provides indexed element access; a list supports access in sequence.
Their possible implementations do not make their names interchangeable.
No disjointness or partial-overlap fact is asserted between these broad classes.
See NIST DADS entries for [array](https://xlinux.nist.gov/dads/HTML/array.html),
[array index](https://xlinux.nist.gov/dads/HTML/arrayindex.html),
[list](https://xlinux.nist.gov/dads/HTML/list.html),
[linked list](https://xlinux.nist.gov/dads/HTML/linkedList.html), and
[data structure](https://xlinux.nist.gov/dads/HTML/dataStructure.html).
The `vector` alias is removed without choosing a mathematical or library-specific
vector meaning on the user's behalf.

The whole-number convention is stated explicitly because terminology varies.
Here whole numbers are 0, 1, 2, …; integers additionally include negative values.
See [OpenStax, Real Numbers](https://openstax.org/books/college-algebra-2e/pages/1-1-real-numbers-algebra-essentials).
A programming integer type specifies representable values and supported operations;
its range and representation depend on the implementation. Python's documented
unlimited precision is an example, not a property attached to every integer type.
[Python numeric types](https://docs.python.org/3/library/stdtypes.html#numeric-types-int-float-complex).

Basic mathematical values stay in the established U1 mathematical-object branch.
Explicit U3 genus links expose the same integer meanings in programming discourse;
1198 retains its original U3 home context. The batch does not populate U2 or clone
a meaning merely to give it a second discourse classification.

Measurement is scoped to obtaining values of physical quantities. Weighing with
scales determines mass; a measuring process and its target quantity are separate
concepts. A comparison involved in measurement does not establish a causal
“produces comparison” assertion.
[BIPM VIM 2.1](https://jcgm.bipm.org/vim/en/2.1.html),
[OIML R 76-1, T.1.1](https://www.oiml.org/en/files/pdf_r/r076-1-e06.pdf#page=5).
The literal verb senses and the noun “измерение” are supported by
[Gramota: измерить](https://gramota.ru/meta/izmerit) and
[Gramota: взвешивать](https://gramota.ru/poisk?mode=slovari&query=взвешивать).
The archived generated measurement nouns are not retained as search aliases;
this does not claim that every unattested formation is linguistically impossible.

The adjective corrections select Russia-wide scope, a relation to Nobel/the
Nobel-prize context, and the literal made-of-rubber property. These meanings
justify leaving color and age; the broader relational-property parent is an
ontology interpretation, not a claim that dictionary word classes are genera.
See [Gramota: всероссийский](https://gramota.ru/poisk?mode=all&query=всероссийский),
[Gramota: Nobel terminology](https://gramota.ru/poisk?mode=spravka&query=Нобелевской&simple=0),
and the entry “Резиновый” in the
[Dictionary of Foreign Words](https://gramota.ru/storage/public/normdicts/slovar_inostr_slov.pdf).
The rubber property is not classified as rubber substance, and the Nobel-related
property is not identified with a prize or a prize recipient.
