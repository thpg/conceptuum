## User controls

- Open **Euler circles** beside Hierarchy and Relations.
- Use **+ Find a concept**, then **+** beside a search result, to add it.
  **+ Add current** adds the currently inspected concept.
- Remove a concept with **×** on its chip. **Clear** empties the diagram.
  These actions only change the display selection; no database editing occurs.
- Compare up to eight concepts. **Context** chooses the discourse universe;
  **Auto diagram** or **Compare pairs** chooses the presentation.
- Select a circle or chip name to inspect that concept. Zoom, pan, fit,
  locate, keyboard navigation, touch zoom, sharing, and SVG export are available.
- Shared URLs preserve the selected IDs, context, and layout, including an
  intentionally empty selection. Concept language can change without losing IDs.

## Relationship rules

The new read-only `/api/euler` endpoint reads accepted relations with a positive
or unspecified strength from one selected context. It returns the selected
concepts, missing IDs, pair classifications, and the source edges supporting
each classification. Requests are limited to eight unique positive IDs.

- Genus (14) establishes containment, including transitive paths.
- Coextension (30) establishes equal extension in either direction and can
  carry inclusion through equivalent concepts.
- Overlap (40) establishes a recorded partial overlap. It is not propagated
  to narrower concepts.
- Incompatibility (60) and contradiction (64) establish disjoint extensions;
  exclusions can descend to narrower concepts.
- Siblings (61), opposites (63), rejected edges, negative relations, and
  relationships from another context do not establish positive set constraints.
- Cycles terminate through visited-node tracking. Conflicting constraints are
  reported instead of forcing an inconsistent circle layout.

Combined diagrams are used for fully known nested, equal, and disjoint sets.
Other selections use independent pair diagrams. This avoids inventing unknown
relationships or a multi-set intersection from binary overlap alone. Unknown
pairs are explicitly labeled and use dashed placeholders: unknown does not mean
disjoint. Circle areas are illustrative, not measured set cardinalities.

The UI and API remain dependent on the quality and completeness of the stored
graph; the Q7 coverage and translation limitations still apply.
