# Q40: conservative lexical cleanup

Q40 corrects spelling and import errors while preserving every concept ID and
relation. This update was published to GitHub and the hosted site on
2026-10-10. The [explicit manifest](../../tools/quality_20261010_q40.json) records
all changes and the labels retained for further review.

## Result

| Measure | Q39 | Q40 |
|---|---:|---:|
| Concepts | 13,456 | 13,456 |
| Accepted edges | 17,350 | 17,350 |
| Rejected edges | 1,100 | 1,100 |
| Genus paths | 64,683 | 64,683 |
| Terms | 37,825 | 31,515 |

- Correct **65 canonical labels**: 60 explicitly inspected malformed generated
  stems and five incorrect neuter adjective forms.
- Remove **6,017 malformed Russian aliases**, including doubled vowels,
  retained infinitive vowels before noun suffixes, and invalid comparative forms.
- Remove **6,836 Russian source verbs incorrectly tagged English**, retaining
  those verbs as Russian terms. This adds 6,543 term rows; the remaining
  Russian spellings already exist, including collation-equivalent forms.
- Rebuild cached definitions from the corrected canonical names. Every edge
  row, rule, context and genus-path row remains exactly unchanged.

The reduction is 12,853 removed term rows minus 6,543 added rows: 6,310 net.
These are lexical changes, not removed meanings or concepts.

## Examples and preservation rules

| Before | Action |
|---|---|
| `задержание` | Keep the valid name and Russian term at concept #7272 |
| `задержаание` | Remove the misspelled alias |
| `вычисляние`, `вычисляяние` | Remove malformed forms; use the original attested verb `вычислять` at #11960 |
| `навредение`, `навредиение` | Remove malformed forms; retain the original verb |
| `рыбее` | Correct the neuter form to `рыбье` |
| `громкее`, `грамматическее` | Remove mechanically generated incorrect comparative forms |
| `электролобзик`, `разговаривание`, `балование`, `ругание` | Retain; rarity or dictionary absence does not establish an error |

No blanket suffix replacement is used as a deletion decision. The removed
concatenation errors reproduce the legacy import's faulty transformation of
an attached source infinitive. Short-verb exceptions and dictionary-attested
forms are preserved. Other stem errors are listed individually in the manifest.

The broader initial candidate set was narrowed after review found valid rare
and productive formations among the unknown words. **4,379 candidate labels
and 4,955 candidate aliases are retained** rather than classified as mistakes.
Those counts describe overlapping review work, not additional proven errors.

Separately, **25 records contain competing original verbs**, for example
`помереть`/`померить` and `пропеть`/`пропить`. These require a sense and ancestry
review. Their canonical labels and relations are preserved; choosing one verb
arbitrarily would discard another meaning. The manifest records the original
verbs and source edges for that review.

## Sources and method

The initial audit checks all concept names and Russian terms against
`pymorphy3 2.0.6` with `pymorphy3-dicts-ru 2.4.417150.4580142`. Its dictionary
membership check is separate from a predicted morphological analysis: a
prediction with a high score is not a dictionary attestation. See the
[analyzer source](https://github.com/no-plagiarism/pymorphy3/blob/master/pymorphy3/analyzer.py).

The second positive check uses the Russian Language Institute's
[published spelling dictionary](https://ruslang.ru/sites/default/files/doc/normativnyje_slovari/orfograficheskij_slovar.pdf),
listed among its [normative dictionaries](https://ruslang.ru/normativnyje_slovari).
The downloaded PDF has SHA-256
`d463813e90a522c0be03c768cd8f159a813b9bde6101b31bf285f53265903a01`.
An accent-normalized extraction contains 129,661 single-word or hyphenated
headwords and positively matches 385 legacy names missed by the morphological
dictionary. Missing matches are inconclusive: coverage and extraction both
have limits. No dictionary text corpus or PDF is added to this repository.

The legacy noun converter now requires `word_is_known()` and a dictionary-backed
parse before accepting a proposed noun. This prevents predicted nonwords from
becoming canonical names; it does not prohibit valid words absent from that
dictionary from being added through a reviewed process.

## Verification and reproducibility

The [repair tool](../../tools/repair_lexicon.py) defaults to read-only validation.
It reads timestamps in UTC and checks all six source-table fingerprints before applying an explicit plan,
requires a backup directory, locks and rechecks source rows, then verifies the
exact expected term set and unchanged graph structure before committing.

On an exact Q39 source database, preview with:

```sh
python tools/repair_lexicon.py tools/quality_20261010_q40.json
```

Applying requires `--apply --backup-dir PATH`. The same plan intentionally
rejects a database already on Q40 or any other changed baseline. Never rerun
historical filling scripts to reproduce this cleanup.

Full backups and intermediate review receipts are kept outside the repository.
The final [verification record](2026-10-10-q40-verification.json) contains table
counts and hashes. Regression checks preserve `задержание`, remove its malformed
alias, retain rare/technical words, and reject stale manifests and invalid
changes. Local SQL and compressed SQL exports contain the final data, with
`utf8_general_ci` explicitly retained on the database and all six tables.

The cleanup does not certify every lexical item or repair semantic relation
errors. Those remain in the [quality queue](../../PLAN.md#immediate-quality-queue-after-q40).
