## Sources and interpretation

The cardinality properties distinguish zero, one, finite, and infinite sizes.
Finite/infinite and empty/nonempty are exhaustive oppositions **within sets**;
finite/nonempty are overlapping classifications.
[OpenStax: basic set concepts](https://openstax.org/books/contemporary-mathematics/pages/1-1-basic-set-concepts).
Subset is relative to a specified containing set and permits equality; proper
subset excludes equality.
[OpenStax: subsets](https://openstax.org/books/contemporary-mathematics/pages/1-2-subsets).

Operation records denote functions, separately from their result sets and from
software implementations. Complement has a fixed domain U; universal set here
means that selected domain. The operation and dependency classifications are
ontology interpretations of
[OpenStax: operations on two sets](https://openstax.org/books/contemporary-mathematics/pages/1-4-set-operations-with-two-sets).
Union and intersection satisfy the commutative and associative laws; difference
does not receive those genera. Algebraic associativity remains separate from
operator parsing conventions. See
[OpenStax: set-operation laws](https://openstax.org/books/contemporary-mathematics/pages/1-5-set-operations-with-three-sets)
and [MIT: algebraic operations](https://ocw.mit.edu/courses/6-972-algebraic-techniques-and-semidefinite-optimization-spring-2006/c3ae2c6021ca407a180a89c01e2cb4a1_lecture_04.pdf).

The ordinary aggregate meaning follows
[Gramota: совокупность](https://gramota.ru/poisk?mode=slovari&query=совокупность).
Concept extension is interpreted relative to a discourse domain, following
[Open Logic: extensionality](https://forallx.openlogicproject.org/html/Ch30.html).
These are explicit sense choices, not claims that all everyday collection
children or every philosophical use of extension have been resolved.

The runtime correction uses the documented software senses of
[Node.js](https://nodejs.org/learn/getting-started/introduction-to-nodejs) and
[Oracle JRE](https://www.oracle.com/java/technologies/jre-8-readme.html).
The latter documents the JVM component in Oracle's Java 8 distribution; this
batch makes no claim about current release packaging or licensing. JVM remains
separate from any particular implementation program.
